    Agentic Hiring

    为字节跳动招聘团队打造的招聘工作台，其中的 Agent 能把一份岗位需求变成排好序的候选人名单，交给用人经理评估。

    Roundtable

    一个群聊形态的多 Agent 协作平台：Agent 团队接过目标，自己商量方案、自己分工，用户在三道关口上掌握全局。
  • 飞书校园 AI 挑战赛 · AI Agent · 记忆与召回

    Lark Loom

    一个住在飞书群聊里的项目 Agent：它记得团队聊出来的结论，并把讨论变成需求文档、分工表格和演示文稿。
  • ACM IUI 2026 · 研究 · Computer-Use Agent · Benchmark

    SusBench

    一个在线 benchmark：在 55 个真实网站中注入 dark pattern，测试 computer-use agent 会不会被这些原本用来骗人的设计骗到。
