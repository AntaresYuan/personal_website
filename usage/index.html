Add a device

These numbers come from a small agent that reads local Claude Code and Codex transcripts and posts daily totals here. It's multi-device: each machine owns its own slot, so several Macs merge instead of overwriting.

Downloads just the agent into ~/.local/share/antares-usage, adds an antares-usage command, then walks through setup. It detects installed tools, pins the device slot, validates the shared bearer and shows a local dry run before uploading anything. Re-running the installer is safe.

Then, any time:

  • local breakdown, no network
  • check config, secret and endpoint
  • upload the latest totals now

Needs macOS (keychain + launchd) and Node. The bearer is intentionally not on this page. Read it from a machine that already syncs with security find-generic-password -a "$USER" -s antares-sync-usage -w. Only token counts, timings and cost leave the machine; prompt and code content never do. Full setup notes →
