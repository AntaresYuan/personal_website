Add a device

These numbers come from a small agent that reads local Claude Code and Codex transcripts and posts daily totals here. It's multi-device: each machine owns its own slot, so several Macs merge instead of overwriting. Setting up another one takes three commands.

  1. 1Clone the repo

  2. 2Run the setup script

    Detects which tools are installed, pins this machine's device slot, then asks for the shared bearer — the endpoint rejects every write without it. The key is checked against the Worker before it's stored, so a mistyped one fails here instead of silently 401-ing on every later run. Local scan and dry-run come before anything is uploaded. Re-runnable.

  3. 3Check what it found

    Local breakdown, no network. --doctor checks the config, the secret and the endpoint if something looks off.

Needs macOS (keychain + launchd) and Node. The bearer isn't on this page by design — read it off a machine that's already syncing: security find-generic-password -a "$USER" -s antares-sync-usage -w. Only token counts, timings and cost leave the machine; prompt and code content never do. Full setup notes →
