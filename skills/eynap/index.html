About

What it is

Research, framing, PRD, entity state machines, design handoff — each written down in a form an AI can read, so an agent can carry a PM's work. One orchestrator decides the stage, routes to a skill and checks the gate; the skills cover value, flow, entity, design, PRD and research; and a shared foundation holds memory, preferences, naming, protocols, host differences and wording rules.

Call the one you need directly — no need to run the whole pipeline.

The chain

Building a product from scratch, the skills run value → flow → entity → design → prd. The PRD comes last because its journey, entity and interaction chapters are those outputs. Research is called on demand, not run first.
