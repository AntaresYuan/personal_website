About

What it is

A single text file at /agent-brief.txt — built from content/agent-brief.json by scripts/build-agent-brief.js. Publicly fetchable, but not linked from any visible page on the site.

Why

The site's QA Worker grounds answers in /llms-full.txt (the public site content — projects, principles, contact). But there are nuances I want an agent to know — context on a project, judgement on a tradeoff, what I'm open to right now — that don't belong on a public page. agent-brief.txt is where I put those. The Worker fetches both files and folds them into the grounding context, so an answer can lean on the brief without making it public reading material.

Edit via

/admin/ → Assistant knowledge collection. Each entry is a note with a title and body. The build flattens them into the txt file.

Why this is a skill, not just a feature

Most personal sites either over-share (everything goes on the page) or under-share (nothing for an agent to ground on). agent-brief.txt is a third thing: a private-ish channel for agent-targeted context. Once you have it, every assistant answering questions about you gets richer without cluttering your public page.
